# PyCon 2026 — CDK Python workshop

A hands-on workshop in building real AWS infrastructure with the AWS CDK in
Python. This repository holds the finished code: five constructs wired into a
single stack that provisions a public API, its DNS, a client-certificate trust
store, and the delivery pipelines for two independently developed services.

**Read the workshop at [czarny.github.io/pycon2026](https://czarny.github.io/pycon2026/)**
— start there. It walks through the same code one construct at a time, and each
step ends with a command that proves what you just wrote. The pages are built
from [`docs/`](docs/README.md) in this repository.
